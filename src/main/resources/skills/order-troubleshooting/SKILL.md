# 订单与物流异常排查

## 步骤
1. 用 getOrder 查订单状态和时间(下单、支付、发货时间)。
2. 按状态分流:
   - PAID 且未发货:现货商品承诺下单支付后48小时内发货,未超时请用户耐心等待;超时则建议联系客服催发货。预售商品以页面标注时间为准。
   - SHIPPED:用 getLogistics 查物流轨迹。
   - UNPAID:提醒订单30分钟未支付会自动关闭。
3. 物流异常判断:
   - 物流信息超过72小时没有更新:建议在订单详情申请催件/查件。
   - 显示已签收但用户没收到:先让用户确认是否被家人、门卫、快递柜代收,仍未找到请在24小时内联系客服核实。
   - 包裹破损或少件:拍照留证,签收后48小时内联系客服。
4. 如需引用具体时效和规则,用 searchKnowledge 检索"配送与签收指南",以检索结果为准。

## 话术要点
- 先说查到的事实(状态、最近一条物流),再给建议。
- 物流接口暂时拿不到数据时,如实告知"物流信息暂时无法获取",并给出订单状态和稍后重试的建议,不要编造轨迹。

## 注意事项
- 订单号必须是16位数字,格式不对时请用户核对。
- 只能查询当前登录用户自己的订单。
