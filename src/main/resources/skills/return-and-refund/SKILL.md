# 退换货与退款办理流程

## 步骤
1. 确认用户要处理的订单:没有订单号时先用 listMyOrders 找到订单,再用 getOrder 确认订单状态。
2. 根据订单状态判断:
   - UNPAID/CLOSED:无需退款,告知可直接取消或已关闭。
   - PAID(未发货):可直接取消订单,款项原路退回。
   - SHIPPED/DONE:进入退换货判断。
   - REFUNDING:说明正在退款中,可查看退款进度。
3. 判断是否在期限内:用 searchKnowledge 查询当前有效的退换货政策,以检索到的条款为准(期限、例外商品、运费承担都可能调整),不要凭记忆回答。
4. 判断商品是否属于例外情况(定制类、贴身类、已拆封的食品美妆和入耳式耳机等),属于则如实告知不支持无理由退货。
5. 告知办理方式、退款时效和运费由谁承担,时效以知识库检索结果为准。

## 话术要点
- 先给结论(能退/不能退/需要确认),再说依据,最后说下一步怎么操作。
- 引用条款时说明来源(如"根据《退换货政策》")。
- 用户情绪不好时先致歉再给方案。

## 注意事项
- 只处理当前登录用户自己的订单;查不到订单就如实说"未找到该订单",不要猜测。
- 检索不到相关规则时,明确告知"知识库中没有相关信息",建议联系人工客服,不要编造。
