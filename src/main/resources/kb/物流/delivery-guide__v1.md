# 配送与签收指南

## 配送范围
支持中国大陆地区配送,暂不支持港澳台及海外地区。

## 发货时效
现货商品在下单支付后48小时内发货;预售商品以商品页面标注的发货时间为准。

## 签收异常处理
### 包裹破损或少件
请在签收时当面验货。发现破损、少件的,请拍照留证,并在签收后48小时内联系客服,核实后补发或退款。

### 显示已签收但没收到
请先联系快递员或确认是否由家人、门卫、快递柜代收。仍未找到的,请在24小时内联系客服,平台将向快递公司核实并跟进赔付。

### 物流长时间不更新
物流信息超过72小时没有更新的,可以在订单详情中申请催件或查件,客服会在24小时内回复处理结果。

### 拒收
未发货前可直接取消订单。已发货后拒收的,商品退回仓库后按退款流程处理,运费由买家承担。
